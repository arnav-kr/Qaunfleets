# Demonstration

1. Open the recorded hybrid plan. Identify required energy, confirmed departures and the feeder limit.
2. Play the schedule. Compare charging visits with the tariff and site-demand charts.
3. Inspect the active QCloud and Opt execution records and independent validation.
4. Run an early-departure or higher-building-load what-if scenario. Explain that this replans the full horizon.
5. Use the evidence view for classical comparisons. State simulator, menu-size and prediction-domain limitations.

Displayed amounts are incremental EV charges in synthetic USD units. Vehicle movement is illustrative; it is not a traffic or routing model.
